# Nandini Thiruvaipati: Portfolio

Multi-page, semantic, accessible portfolio (HTML5 + CSS, no build step).

Pages: index.html, about.html, projects.html, contact.html

## Deploy on GitHub Pages
1. Create a new public repo (e.g. `portfolio`) on github.com.
2. Upload all files from this folder (keep `css/` folder) to the repo root.
3. Repo > Settings > Pages > Source: "Deploy from a branch" > `main` / `(root)` > Save.
4. Open `https://<your-username>.github.io/portfolio/`.

## Notes
- Contact form uses formsubmit.co. The first submission sends a one-time activation email to the address in the form's `action`; click confirm.
- Update the AirDraw link in projects.html to your exact repo/live demo URL.
